# Changelog

## 1.0.0 (2026-06-09)

First public release of **Seekiee** by [Darkiee](https://darkiee.com).

- Full CLI engine: A–G offer evaluation, tailored ATS PDF generation, portal scanner (Greenhouse / Lever / Ashby), pipeline tracker with integrity checks, batch processing, interview prep + STAR story bank, follow-up cadence, pattern analytics
- Runs as a skill in Claude Code, Gemini CLI, OpenCode, Codex, Qwen, and Copilot CLI
- English, German, French, Japanese, and Turkish evaluation modes

Future releases will be documented here.
